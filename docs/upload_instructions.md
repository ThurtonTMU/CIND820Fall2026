# Add this prepared batch to GitHub

Target: https://github.com/ThurtonTMU/CIND820Fall2026

The GitHub connection uses **ThurtonTMU** and has write access. For future batches, prepare the files, validate them, commit to a review branch and open a draft pull request. The manual instructions below are an optional alternative.

## If uploading in the GitHub website

1. Extract the prepared repository ZIP on your PC.
2. Open the repository and choose **Add file → Upload files**.
3. Upload the extracted contents at the repository root, preserving the `data`, `docs`, `results` and `scripts` directories. Replace the original short README with the prepared README.
4. Include `.gitignore`; if Windows hides it or the upload omits it, create it separately using the included contents.
5. Do not upload `data/private/`, credentials, personal records or environment folders. They are excluded from this prepared ZIP.
6. Commit to a new branch, for example `batch01-payment-boundary`, for a reviewable first batch.

## If using VS Code and Git

Clone the existing repository first, copy the prepared authored files into it, then use Source Control to review the diff and commit to a new branch. This preserves the existing repository history. The prepared package contains no Git history and should not replace the remote repository with an unrelated initial commit.

To capture your own local vendor snapshots, follow the README commands. A new capture may differ from the original checksums; review drift before accepting a new snapshot basis. Existing published metadata records the original research capture even when raw documents are not redistributed.
